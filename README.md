# Student Feedback Form (DevOps CA2)

A static Student Feedback Form (HTML, CSS, JavaScript validation), deployed with GitHub Pages and tested with Selenium.

- `index.html`, `styles.css`, `script.js`: the web app
- `selenium-tests/test_form.py`: Selenium functional tests (valid and invalid inputs)

Run tests locally:

    pip install selenium
    python selenium-tests/test_form.py
CI trigger test
